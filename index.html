VERBINDE DEINE SAMMLUNG

Von Pawchive zu seen.

Status

Fehlende Bilder werden bei verbundenem Skript automatisch ergänzt.

Skript-Version 2.19.1 verbindet Pawchive mit deiner Mediathek und bringt die Rahmen-Einstellungen mit. Ersetze den Code deines bestehenden Violentmonkey-Skripts und lade beide Seiten neu. Verwende beide Seiten im selben Browser und Violentmonkey-Profil. Deine im Skript gespeicherten Markierungen bleiben erhalten.

  1. Skript aktualisieren

    Öffne dein bestehendes Violentmonkey-Skript und ersetze den gesamten Code. Name und Speicher bleiben gleich.

    Skript herunterladen
    Code anzeigen / manuell kopieren
  2. Beide Seiten neu laden

    Speichere das Skript, bestätige gegebenenfalls die Website-Berechtigung in Violentmonkey und lade Pawchive und dieses Dashboard neu. Oben erscheint „Auto-Sync verbunden“. Öffne das Dashboard direkt über seine Adresse, nicht in einer eingebetteten Vorschau.

  3. Optional: Backup & Rahmen

    Manuelle JSON-Backups funktionieren weiterhin. Bei aktivem Auto-Sync werden importierte Änderungen mit dem Skript abgeglichen.

Ältere Markierungen enthalten zunächst nur IDs. Fehlende Titel und Vorschaubilder werden im Hintergrund von den gespeicherten Post-Seiten geladen; erlaube dafür die Pawchive-Verbindung, falls Violentmonkey fragt. Auto-Sync funktioniert innerhalb desselben Browserprofils, nicht zwischen Geräten. Sichere deine Sammlung regelmäßig als Backup.

Backup kopieren
